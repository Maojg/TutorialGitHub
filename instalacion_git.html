Instalación de Git

Para instalar Git, sigue estos pasos:

  1. Visita la página oficial de Git: git-scm.com
  2. Selecciona tu sistema operativo (Windows, macOS, Linux).
  3. Descarga el instalador y sigue las instrucciones.
  4. Verifica la instalación abriendo una terminal y escribiendo git --version.

    5. Para instalar Git, descarga el instalador oficial desde git-scm.com y sigue las instrucciones de tu sistema operativo.
