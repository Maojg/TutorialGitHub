Configuración de Git

Para configurar Git, sigue estos pasos:

  1. Abre la terminal.
  2. Configura tu nombre de usuario: git config --global user.name "Tu Nombre"
  3. Configura tu correo electrónico: git config --global user.email "
  4. Verifica la configuración: git config --list

Estos comandos configuran tu nombre y correo electrónico, que se usarán en los commits.
